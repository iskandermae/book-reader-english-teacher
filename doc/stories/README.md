## Definition of Done (every story)
- Backend logic covered by unit tests;
- Visible user result, or a clearly labelled technical enabler / spike.

## Story types
- **Story**: user-visible value.
- **Enabler**: technical prerequisite, testable via API or tests.
- **Spike**: timeboxed research, output is a written decision record in `doc/decisions/`.
