# web

Angular GUI. Talks to the backend only through the generated client.

## Commands
| What | Command |
|---|---|
| Dev server (proxies `/api` to `http://localhost:5027`) | `npm start` |
| Build / tests | `npm run build` / `npm test -- --watch=false` |
| Regenerate API client | `npm run api:generate` |

Start the backend first: `dotnet run --project src/BookReader.Api`.

## Generated API client
- Generated by `@hey-api/openapi-ts` (`openapi-ts.config.ts`) from `../api/openapi.json` into `src/app/api/`.
- **Decision: generated code is git-ignored**, not committed. The contract is the single source of truth, so a committed copy could go stale and add noisy diffs. `start`, `build` and `test` run `api:generate` first (npm `pre*` scripts), so a fresh clone needs only `npm ci`. CI needs no extra step.
- Never edit generated files.
- The contract's `servers` URL is the test host and is ignored: `app.config.ts` sets the client `baseUrl` to `''` (relative `/api/...`). In dev `proxy.conf.json` forwards `/api` to the backend.
